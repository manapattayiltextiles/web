# Indra Image Assets

Add the six supplied garment images to this folder using these filenames:

1. `blue-kurti-details.jpg` - blue kurti, sleeve variations and construction details.
2. `cocoa-embroidered-kurti.jpg` - cocoa embroidered kurti product image.
3. `embroidered-kurti-colourways.jpg` - embroidered kurti shown in cocoa, plum and teal.
4. `everyday-dress-colours.jpg` - everyday dresses shown in yellow, red and berry.
5. `mustard-workwear-kurta.jpg` - mustard kurta with blue details and workwear styling.
6. `floral-kurta-styling.jpg` - mint floral kurta with styling and detail views.

The pages use these local paths and fall back to editorial placeholder photography while an asset is unavailable.
